01

Where do facts live?

If a model completes "Michael Jordan plays the sport of ___" with basketball, then somewhere in its parameters is an association between one particular person and one sport.

In December 2023, researchers at Google DeepMind looking at this question found that facts seem to be stored in a particular part of the network: the multi-layer perceptrons (MLPs). Nobody fully understands the mechanism yet. 3b1b's lesson describes it as unsolved. What we can do is build a toy MLP that clearly stores a fact, and check that real MLPs have the right structure to work the same way.

🔁

Attention: vectors talk

Information moves between positions. For example, "Michael" passes its meaning forward onto "Jordan".

🧱

MLP: vectors think alone

Each position is processed on its own and in parallel, with no communication. This is where a looked-up fact gets added.

📦

Most of the weights

In GPT-3 the MLP blocks hold about 116 B of the 175 B parameters, roughly two-thirds.

This page follows on from the multi-head attention notebook. A transformer layer is attention followed by an MLP, and GPT-3 repeats that 96 times. Both blocks add their output to the residual stream: $\vec E \to \vec E + \text{Attn}(\cdot) \to \cdots + \text{MLP}(\cdot)$.
02

Facts as directions

Recall from the embeddings chapter that directions in embedding space can carry meaning. For example, woman − man points along a "gender" direction. We'll assume three such directions exist, nearly perpendicular to one another.

DirectionMeaningHow to read it
$\vec M$first name Michael$\vec E\cdot\vec M = 1$ → "this token's person is called Michael". A value of 0 or below means it isn't.
$\vec J$last name Jordan$\vec E\cdot\vec J = 1$ → "surname Jordan".
$\vec B$basketballWe want the MLP to add this direction whenever the vector encodes the full name.

So "the vector encodes Michael Jordan" means $\vec E\cdot\vec M=1$ and $\vec E\cdot\vec J=1$. Attention already did part of the work: an earlier attention layer moved "Michael" forward onto the "Jordan" token, so that one vector now holds both names. (We ignore dot products greater than 1, as the video does.)

03

The MLP in 3D: watch a fact get looked up

The whole block, as the video puts it, is "two matrix products, each with a bias added, and a simple clipping function in between", followed by a residual add.

$$ \vec E' \;=\; \vec E \;+\; W_{\downarrow}\,\operatorname{ReLU}\!\big(W_{\uparrow}\vec E + \vec b_{\uparrow}\big) + \vec b_{\downarrow} $$

Below is a toy MLP with a 12-dimensional embedding and 48 neurons, the same 4× expansion GPT-3 uses (12,288 → 49,152). The first 8 embedding dimensions are named features. Neuron 0 is wired by hand to detect "Michael AND Jordan", and neuron 1 to detect "Michael AND Phelps". The other 46 have random small weights, standing in for every other feature the model knows. 04

Step 1: the up-projection asks questions

Multiply $\vec E$ by a very large matrix $W_\uparrow$. Each row is a question, and each output entry is the dot product of that row with $\vec E$.

If row 0 were just $\vec M$, the output would be "is the first name Michael?". Make row 0 equal to $\vec M+\vec J$ instead. Dot products distribute, so:

$$ (\vec M+\vec J)\cdot\vec E \;=\; \vec M\cdot\vec E+\vec J\cdot\vec E \;=\; \begin{cases} 2 & \text{Michael Jordan}\\ 1 & \text{Michael Phelps, or Alexis Jordan}\\ 0 & \text{neither}\end{cases} $$

This is a problem: "Michael Phelps" scores 1 here, half as much as Michael Jordan. A purely linear map can't separate "both" from "one of the two". The fix is the bias $\vec b_\uparrow$. Set its first entry to $-1$:

$$ h_0^{\text{pre}} = (\vec M+\vec J)\cdot\vec E - 1 = \begin{cases} +1 & \text{Michael Jordan}\\ \;\;\,0 & \text{only one name}\\ -1 & \text{neither}\end{cases} $$

Now the entry is positive if and only if the vector encodes the full name. In GPT-3, $W_\uparrow$ has 49,152 rows ("just under 50,000"), exactly 4 × 12,288. There's no deep reason for the 4×. It's a design choice that stuck.

05

Step 2: ReLU turns it into an AND gate

Next, a non-linear function is applied to every entry. ReLU keeps positive numbers and replaces negative ones with zero.

$$ \operatorname{ReLU}(x)=\max(0,x)\qquad \operatorname{GELU}(x)= x\,\Phi(x)\approx \tfrac12 x\Big(1+\tanh\!\big[\sqrt{2/\pi}\,(x+0.044715x^3)\big]\Big) $$

After the $-1$ bias, $\operatorname{ReLU}(h_0^{\text{pre}})$ is 1 for Michael Jordan and exactly 0 for everyone else: an AND gate built from a dot product, a bias and a clip. The outputs of the ReLU are the neurons. A neuron is active when its value is positive and inactive when it is zero. Real models usually use GELU, which has the same shape but is smooth around 0 and lets small negative values through.

Quick check: how many parameters does ReLU have? Zero. It's a fixed function applied to each entry. Everything the MLP learns is in $W_\uparrow, \vec b_\uparrow, W_\downarrow, \vec b_\downarrow$.
06

Step 3: the down-projection writes the answer

$W_\downarrow$ maps the 49,152 neurons back to the 12,288 embedding dimensions. Read it column by column.

$$ W_\downarrow\,\vec h \;=\; \sum_{n} h_n\,\vec c_n \qquad(\vec c_n=\text{column } n \text{ of } W_\downarrow) $$

Each column is a direction in embedding space that gets added only when its neuron is active, scaled by the neuron's value. Set column 0 to $\vec B$, the basketball direction. When neuron 0 fires (Michael Jordan), "basketball" is added. When it's 0, nothing is. The same column can carry more associations at once, such as Chicago Bulls or the number 23. Then comes the bias $\vec b_\downarrow$, added regardless (it's safe to ignore), and the residual add:

$$ \vec E' = \vec E + \Delta\vec E,\qquad \Delta\vec E = \underbrace{1}_{h_0}\cdot\vec B + \cdots \;\;\Rightarrow\;\; \vec E'\cdot\vec B \approx 1 $$

The output vector now encodes Michael, Jordan and basketball. Every token position runs this independently and in parallel, so one block computes 49,152 × (number of tokens) neuron values.

Rows read, columns write. Each row of $W_\uparrow$ is a pattern detector for the input. Each column of $W_\downarrow$ is a message to add to the output. A neuron connects one to the other, so a single neuron can act as one entry in a key → value lookup table.

09

Superposition: more facts than neurons

In $n$ dimensions you can fit only $n$ exactly perpendicular directions. "To a mathematician this is the definition of dimension." But if nearly perpendicular is good enough, say 85–95° apart, the count changes dramatically.

$$ \textbf{Johnson–Lindenstrauss:}\quad \#\{\text{nearly perpendicular directions}\}\ \text{grows exponentially with } n,\qquad N \sim e^{\,c\,\varepsilon^2 n} $$

A space with 10× more dimensions can hold far more than 10× more independent ideas. So the 49,152 neurons could probe orders of magnitude more features, with each feature spread across a combination of neurons rather than owning one. That is what superposition means here.

Random directions are already nearly perpendicular in high dimensions. For two random unit vectors in $n$ dimensions, the dot product has mean 0 and standard deviation $1/\sqrt n$, so the angle stays within about $\pm 57.3^\circ/\sqrt n$ of 90°. Run the experiment yourself:

10

Real neurons are messy

Our toy neuron 0 is a clean feature: one neuron, one meaning. In real models, single neurons "very rarely" look like that.

Superposition explains why. If the model stores far more features than it has neurons, each feature has to be a direction spread across many neurons, and each neuron takes part in many unrelated features. A single neuron may fire for Michael Jordan, Korean poetry and HTML tags. This makes models hard to interpret. It may also be part of why they scale so well: each extra dimension adds more than one dimension's worth of capacity.

🧩

Polysemantic neurons

One neuron, many unrelated meanings. That's what you'd expect if features are overlapping, nearly perpendicular directions.

🔬

Sparse autoencoders

Interpretability researchers train an SAE to rewrite the activations as a sparse mix of many more directions, trying to recover the real features.

11

Code it

First, the MLP block as it appears in a GPT-style model. Second, the hand-wired Michael Jordan neuron from this page, which you can run.

import torch, torch.nn as nn

class MLPBlock(nn.Module):
    def __init__(self, d=12288, mult=4):
        super().__init__()
        self.norm = nn.LayerNorm(d)
        self.up   = nn.Linear(d, mult * d)     # W↑, b↑ : rows = questions
        self.act  = nn.GELU()                   # smooth ReLU, 0 params
        self.down = nn.Linear(mult * d, d)     # W↓, b↓ : columns = answers

    def forward(self, x):                   # x: (B, n, d); every position independent
        return x + self.down(self.act(self.up(self.norm(x))))   # E' = E + ΔE

# ---- the toy "Michael Jordan" neuron ----
M, J, B, P = torch.eye(4)                   # Michael, Jordan, basketball, Phelps
W_up   = torch.stack([M + J])                # 1 neuron: row 0 = M + J
b_up   = torch.tensor([-1.0])
W_down = B[:, None]                         # column 0 = basketball

for name, E in [("Michael Jordan", M+J), ("Michael Phelps", M+P)]:
    h  = torch.relu(W_up @ E + b_up)         # AND gate
    E2 = E + W_down @ h
    print(name, "h0 =", h.item(), " E'·B =", (E2 @ B).item())
# Michael Jordan h0 = 1.0  E'·B = 1.0
# Michael Phelps h0 = 0.0  E'·B = 0.0
Parameter check: sum(p.numel() for p in MLPBlock().parameters()) gives 1,208,045,568. That's the 1,207,959,552 weights in the table plus 61,440 biases and 24,576 LayerNorm parameters.
12

Recap

  • The MLP is up-project, then a non-linearity, then down-project, then add: $\vec E' = \vec E + W_\downarrow\,\sigma(W_\uparrow\vec E+\vec b_\uparrow)+\vec b_\downarrow$. Every token is processed independently.
  • Rows of $W_\uparrow$ are questions about the input (dot products). The bias sets a threshold. ReLU clips at zero, so together they make an AND gate.
  • Columns of $W_\downarrow$ are what gets written: an active "Michael Jordan" neuron adds the basketball direction, and possibly Bulls and 23 too.
  • Size: 2 × 12,288 × 49,152 ≈ 1.2 B per block, and 116 B over 96 layers, about two-thirds of GPT-3.
  • Superposition: nearly perpendicular directions grow exponentially with dimension (Johnson–Lindenstrauss). So features outnumber neurons and individual neurons look messy. Sparse autoencoders try to recover the features.
