The big picture

A Transformer encoder turns raw text into context-rich vectors — one per token, each rewritten in light of every other token. It's a pipeline of simple, shape-preserving steps repeated N times.

Below, the entire pipeline is laid out as a single animation you can watch like a GIF. Every stage names the data passing through it, the operation applied, the tensor shape before and after, and the number of learnable parameters involved. We'll use a running example with these sizes throughout:

batch = 32  ·  sequence length L = 24  ·  dmodel = 64  ·  heads = 4  ·  head dim = 16  ·  dff = 256

04

Inside one encoder layer

Each of the N layers is the same four moves: attention, Add&Norm, feed-forward, Add&Norm — with a residual skip wrapped around each sub-layer.

Why the residual skip? Adding the input back (x + SubLayer(x)) gives gradients a clean shortcut straight back through the network, so very deep stacks don't lose signal. The sub-layer only has to learn a small correction to x, not rebuild it.
05

Tokens → embeddings

Text becomes numbers in two steps: a tokenizer splits the string into IDs, then an embedding table maps each ID to a dense vector.

The tokenizer turns "the cat sat" into integer IDs of shape [32, 24] (batch × sequence). The embedding layer is a lookup table with one learnable row per vocabulary entry; it expands each ID into a dmodel=64 vector, giving [32, 24, 64]. Similar words land near each other — but at this point each vector is still context-free.

tokens [32, 24]  —embed→  X [32, 24, 64]  ·  params = vocab_size × 64
06

Positional encoding

Self-attention is order-blind — it sees a set, not a sequence. Positional encoding stamps order back in by adding a position-dependent vector to every embedding.

The original Transformer builds these from sine and cosine waves of many frequencies. Each position gets a unique, smooth signature; nearby positions look similar, and the pattern extrapolates to longer sequences than seen in training. It's parameter-free.

PE(p,2i) = sin( p / 100002i/d )    PE(p,2i+1) = cos( p / 100002i/d )

Shapes don't change — we just add: [32,24,64] ＋ PE [24,64] → [32,24,64]. This sum is the actual input to encoder layer 1.

07

Multi-head self-attention

The heart of the encoder. Each token asks "who else is relevant to me?" and blends in their information. Done in several parallel heads.

7.1 — Q, K, V projection

The input is projected by three learned matrices into a Query, a Key, and a Value, then split across heads. With 4 heads, the 64-dim model splits into four 16-dim subspaces:

Q, K, V each: [32, 4, 24, 16]   (batch, heads, seq, head dim)
🔍

Query (Q)

What this token is looking for.

🏷️

Key (K)

What each token advertises, to be matched against queries.

📦

Value (V)

The content a token contributes once it's matched.

7.2 — Scores: Q × Kᵀ, scaled

Every query dots with every key to produce a relevance score. Transpose K to [32,4,16,24] so the matmul lines up, then divide by √dk = √16 = 4 to keep scores from exploding:

Q [32,4,24,16] × Kᵀ [32,4,16,24]  =  scores [32,4,24,24]  ÷ √dk

That [32,4,24,24] is one 24×24 attention map per head — every token's relevance to every other token.

7.3 — Softmax → weights → weighted sum

Each row of the score matrix goes through softmax, becoming positive weights that sum to 1. Multiply those weights by V to get each token's context vector. Below is a real 8-token attention map (rows = queries, columns = keys); brighter = more attention.

≈0 (ignored)≈1 (strong attention)
Attention(Q,K,V) = softmax( Q·Kᵀ / √dk ) · V

7.4 — Concatenate heads & project

The four head outputs [32,4,24,16] are concatenated back to [32,24,64] and passed through a final output projection WO. The block's output shape exactly matches its input — ready for Add & Norm.

08

Add & LayerNorm

After each sub-layer: add the residual, then normalize. LayerNorm steadies the activations so the deep stack stays trainable.

out = γ · (x − μ) / √(σ² + ε) + β  ·  params = 2 × 64 = 128 per norm

γ (scale) and β (shift) are the only learnable parameters — they let the network undo the normalization if a layer needs to.

LayerNorm vs BatchNorm. BatchNorm normalizes each feature across the batch (needs a big, stable batch). LayerNorm normalizes within each token vector, independent of the batch and other positions — perfect for variable-length sequences and batch-size-1 inference. That independence is exactly why Transformers use LayerNorm.

09

Feed-forward network (MLP)

11

Summary

Embed the words, stamp in their positions, then repeat a two-step refinement N times: let every token attend to every other token, then let each token rethink itself — residuals and LayerNorm keeping it stable enough to stack deep.

The one-line mental model: attention lets tokens talk; the feed-forward net lets each token think; Add & Norm keeps the conversation stable — and the shape never changes, so the block stacks N times into the final contextual embeddings.
Tokenize → embed → +position → (attention → Add&Norm → FFN → Add&Norm) × N → output
One pipeline, every shape preserved, watched end to end.
