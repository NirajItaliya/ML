01

The core idea

Training a network means nudging every weight so the output gets closer to the target. Backpropagation is just an efficient way to compute, for each weight, which direction reduces the error — using the chain rule of calculus.

We train with stochastic gradient descent: for one training example $d$ at a time, we descend the gradient of the error $E_d$. Every weight $w_{ji}$ gets a correction:

$$ w_{ji} \;\leftarrow\; w_{ji} + \Delta w_{ji}, \qquad \Delta w_{ji} = -\eta\,\frac{\partial E_d}{\partial w_{ji}} $$

Here $\eta$ is the learning rate. The whole derivation below is about turning that abstract derivative $\partial E_d/\partial w_{ji}$ into something we can actually compute, layer by layer.

The name says it all: errors are computed at the output and propagated backwards through the network, so each hidden weight learns how much it contributed to the mistake.

Three ways to picture it

🏔️

Walking downhill blind

The error is a landscape; the weights are your position. You can't see the valley, but you can feel the slope under your feet (the gradient) and step downhill. $\eta$ is your stride length.

🍲

Assigning the blame

The dish came out too salty (the error). Backprop asks each cook — each weight — "how much of this was your fault?" and tells them exactly how much to change next time.

🎛️

Turning the right knobs

Each weight is a knob. The term $\delta_j$ tells a neuron which way to turn its knobs and how hard — bigger blame, bigger turn.

Notation

SymbolMeaning
$x_{ji}$the $i$-th input to unit $j$
$w_{ji}$weight on the $i$-th input to unit $j$
$net_j$weighted sum of inputs for unit $j$,   $net_j=\sum_i w_{ji}x_{ji}$
$o_j$the output computed by unit $j$
$t_j$the target output for unit $j$
$\sigma$the sigmoid (logistic) activation function
Downstream$(j)$units that take $o_j$ as an input

Each unit computes $net_j=\sum_i w_{ji}x_{ji}$, then squashes it: $o_j=\sigma(net_j)=\dfrac{1}{1+e^{-net_j}}$.

03

The derivation

A weight $w_{ji}$ can only affect the error through $net_j$. So the chain rule splits the gradient in two:

$$ \frac{\partial E_d}{\partial w_{ji}} \;=\; \frac{\partial E_d}{\partial net_j}\,\frac{\partial net_j}{\partial w_{ji}} \;=\; \frac{\partial E_d}{\partial net_j}\,x_{ji} $$

The only thing left to find is $\partial E_d/\partial net_j$. There are two cases.

Case 1 — output units

An output unit can be compared directly to its target. Working through the squared-error and the sigmoid derivative $\sigma'=\sigma(1-\sigma)$ gives:

$$ \frac{\partial E_d}{\partial net_j} = -(t_j-o_j)\,o_j(1-o_j) \;\;\Rightarrow\;\; \boxed{\;\delta_j = (t_j-o_j)\,o_j\,(1-o_j)\;}$$

Case 2 — hidden units

A hidden unit has no target. Its error is borrowed from every downstream unit it feeds, weighted by the connecting weights — this is the "backward" flow:

$$ \boxed{\;\delta_j = o_j(1-o_j)\!\!\sum_{k\in \text{Downstream}(j)}\!\!\delta_k\,w_{kj}\;}$$

One rule for every weight

Both cases collapse into a single, beautiful update — the only difference is how $\delta_j$ is computed:

$$ \Delta w_{ji} = \eta\,\delta_j\,x_{ji} $$
Unit typeError term $\delta_j$
Output$\delta_j=(t_j-o_j)\,o_j(1-o_j)$
Hidden$\delta_j=o_j(1-o_j)\sum_k \delta_k w_{kj}$

06

Worked examples

Three fully-solved networks, increasing in richness: a sigmoid net, a linear matrix form, and the classic example with biases and two outputs.

6.1 — Sigmoid network (single output)

Forward pass. With $x_1=0.35,\;x_2=0.9$:

$$\begin{aligned} a_1&=(0.1)(0.35)+(0.8)(0.9)=0.755,& y_3&=\tfrac{1}{1+e^{-0.755}}=0.68\\ a_2&=(0.4)(0.35)+(0.6)(0.9)=0.68,& y_4&=\tfrac{1}{1+e^{-0.68}}=0.6637\\ a_3&=(0.3)(0.68)+(0.9)(0.6637)=0.801,& y_5&=\tfrac{1}{1+e^{-0.801}}=0.69 \end{aligned}$$

Error $=y_{target}-y_5 = 0.5-0.69=-0.19$.

Backward pass. Output delta, then hidden deltas:

$$\begin{aligned} \delta_5&=y_5(1-y_5)(y_{target}-y_5)=0.69(0.31)(-0.19)=-0.0406\\ \delta_3&=y_3(1-y_3)\,w_{35}\,\delta_5=0.68(0.32)(0.3)(-0.0406)=-0.00265\\ \delta_4&=y_4(1-y_4)\,w_{45}\,\delta_5=0.6637(0.3363)(0.9)(-0.0406)=-0.0082 \end{aligned}$$

These feed the update $\Delta w_{ji}=\eta\,\delta_j\,o_i$ to adjust every weight.

6.2 — Matrix / gradient-descent form (linear)

Sample: inputs $[2,\;3]$, target $[1]$. Forward pass:

$$\begin{bmatrix}2&3\end{bmatrix}\!\begin{bmatrix}0.11&0.12\\0.21&0.08\end{bmatrix}=\begin{bmatrix}0.85&0.48\end{bmatrix}\!\begin{bmatrix}0.14\\0.15\end{bmatrix}=\begin{bmatrix}0.191\end{bmatrix}$$

Error $=\tfrac12(\text{prediction}-\text{actual})^2=\tfrac12(0.191-1.0)^2=0.327$. Each weight is updated by gradient descent:

$$W_x^{*}=W_x-a\left(\frac{\partial \text{Error}}{\partial W_x}\right),\qquad \Delta=\text{prediction}-\text{actual}=-0.809,\quad a=0.05$$

Updating the output weights, then the input weights:

$$\begin{bmatrix}w_5\\w_6\end{bmatrix}=\begin{bmatrix}0.14\\0.15\end{bmatrix}-0.05(-0.809)\begin{bmatrix}0.85\\0.48\end{bmatrix}=\begin{bmatrix}0.17\\0.17\end{bmatrix}$$
$$\begin{bmatrix}w_1&w_3\\w_2&w_4\end{bmatrix}=\begin{bmatrix}.11&.12\\.21&.08\end{bmatrix}-0.05(-0.809)\begin{bmatrix}2\\3\end{bmatrix}\!\begin{bmatrix}0.14&0.15\end{bmatrix}=\begin{bmatrix}.12&.13\\.23&.10\end{bmatrix}$$
After one update the prediction rises from 0.191 → 0.26, and the error drops from 0.327 to ≈ 0.27 — the network is learning.

6.3 — Sigmoid network with biases and two outputs

Inputs $i_1=0.05,\;i_2=0.10$; targets $T_1=0.01,\;T_2=0.99$; learning rate $\eta=0.5$. Forward pass:

$$\begin{aligned} \text{out}_{h_1}&=\sigma(0.15{\cdot}0.05+0.20{\cdot}0.10+0.35)=\sigma(0.3775)=0.59327\\ \text{out}_{h_2}&=\sigma(0.25{\cdot}0.05+0.30{\cdot}0.10+0.35)=\sigma(0.3925)=0.59689\\ \text{out}_{o_1}&=\sigma(0.40{\cdot}0.59327+0.45{\cdot}0.59689+0.60)=\sigma(1.10591)=0.75137\\ \text{out}_{o_2}&=\sigma(0.50{\cdot}0.59327+0.55{\cdot}0.59689+0.60)=\sigma(1.22492)=0.77293 \end{aligned}$$

Backward pass — output layer:

$$\begin{aligned} \delta_{o_1}&=(0.01-0.75137)(0.75137)(1-0.75137)=-0.13850\\ \delta_{o_2}&=(0.99-0.77293)(0.77293)(1-0.77293)=0.03810 \end{aligned}$$

Backward pass — hidden layer:

$$\begin{aligned} \delta_{h_1}&=(\delta_{o_1}w_5+\delta_{o_2}w_7)\,\text{out}_{h_1}(1-\text{out}_{h_1})=-0.00877\\ \delta_{h_2}&=(\delta_{o_1}w_6+\delta_{o_2}w_8)\,\text{out}_{h_2}(1-\text{out}_{h_2})=-0.00995 \end{aligned}$$
