01

The big idea

A word's meaning depends on the words around it. Self-attention is the mechanism that lets every token look at every other token in the sentence and rebuild itself as a context-aware blend of them all.

Before transformers, sequence models (RNNs) read a sentence one word at a time and struggled to carry information across long distances. Attention fixed that by giving every position direct access to every other position at once — and the 2017 paper Attention Is All You Need showed you could drop the RNN entirely and keep only attention. That is the engine inside GPT, Llama, and friends.

The version we build here is the original scaled dot-product attention. It is still the one most models use, because attention is rarely the computational bottleneck worth replacing.

Three ways to picture it

🗂️

A soft dictionary lookup

Each token issues a query ("what am I looking for?"). Every token also advertises a key ("what I'm about"). You match query against keys — but instead of one exact hit, you blend all matches by how well they fit.

🎧

A room full of voices

The word "it" turns to the room and asks "who do I refer to?" Every other word answers at some volume. "it" then mixes those answers — loud where relevant, quiet where not — into its new meaning.

🍹

A weighted cocktail

The output for a token is a recipe: take a little of this token's value, a lot of that one's, blended by the attention weights. The weights sum to 1, so it's always a proper mix.

We'll make this concrete with one sentence — "Life is short, eat dessert first" — and actually compute the context vector for one word, by hand and in PyTorch.
02

Embedding a sentence

Models don't see words; they see vectors. First we map each unique word to an integer, then look up a learned embedding vector for it. We use a tiny 3-dimensional embedding so the numbers fit on the page (real models use hundreds–thousands; Llama 2 uses 4096).

import torch
sentence = 'Life is short, eat dessert first'
dc = {s:i for i,s in enumerate(sorted(sentence.replace(',','').split()))}
sentence_int = torch.tensor([dc[s] for s in sentence.replace(',','').split()])

torch.manual_seed(123)
embed = torch.nn.Embedding(50_000, 3)
embedded_sentence = embed(sentence_int).detach()   # shape: [6, 3]
tensor([[ 0.3374, -0.1778, -0.3035], # Life [ 0.1794, 1.8951, 0.4954], # is [ 0.2692, -0.0770, -1.0205], # short [-0.2196, -0.3792, 0.7671], # eat [-0.5880, 0.3486, 0.6603], # dessert [-1.1925, 0.6984, -1.4097]]) # first

Six words, each a 3-D vector — a $6\times3$ matrix we'll call $X$. Every row is one token. The whole job of self-attention is to turn each of these rows into a richer, context-aware row.

03

Query, Key, Value — three projections

Self-attention learns three weight matrices, $W_q,\,W_k,\,W_v$. Each input row $x^{(i)}$ is multiplied by all three to produce a query, a key, and a value for that token:

$$ q^{(i)} = x^{(i)}W_q, \qquad k^{(i)} = x^{(i)}W_k, \qquad v^{(i)} = x^{(i)}W_v $$

Query and key must be the same length $d_k$ (we take their dot product). The value length $d_v$ can be anything — it sets the size of the final output. For this walkthrough: input size $d=3$, and $d_q=d_k=2$, $d_v=4$.

torch.manual_seed(123)
d = embedded_sentence.shape[1]      # 3
d_q, d_k, d_v = 2, 2, 4

W_query = torch.nn.Parameter(torch.rand(d, d_q))   # 3x2
W_key   = torch.nn.Parameter(torch.rand(d, d_k))   # 3x2
W_value = torch.nn.Parameter(torch.rand(d, d_v))   # 3x4
Why three roles? The query is what a token is searching for. The key is what each token offers as a label. The value is the actual content that gets passed along once a match is found. Separating "how to match" (q·k) from "what to deliver" (v) is what gives attention its flexibility.
04

Attention scores — how much does each token matter?

Let's focus on the second token, "is" ($x^{(2)}$), as the query. We score it against every token by taking the dot product of its query with each key. Bigger dot product = more relevant.

$$ \omega_{2,j} = q^{(2)} \cdot k^{(j)} $$
x_2 = embedded_sentence[1]
query_2 = x_2 @ W_query        # shape [2]
keys    = embedded_sentence @ W_key     # shape [6, 2]
values  = embedded_sentence @ W_value   # shape [6, 4]

omega_2 = query_2 @ keys.T     # raw scores against all 6 tokens
tensor([-0.6004, 3.4707, -1.5023, 0.4991, 1.2903, -1.3374])

Notice the second entry (3.47) is huge: token 2's query matches its own key most strongly. These are the unnormalized scores $\omega$ — not yet a clean set of weights.

05

Softmax & the $\sqrt{d_k}$ scaling

Two things turn raw scores into usable weights $\alpha$: divide by $\sqrt{d_k}$, then apply softmax so they're positive and sum to 1.

$$ \alpha_{2,j} = \operatorname{softmax}\!\left(\frac{\omega_{2,j}}{\sqrt{d_k}}\right) $$
import torch.nn.functional as F
attention_weights_2 = F.softmax(omega_2 / d_k**0.5, dim=0)
tensor([0.0386, 0.6870, 0.0204, 0.0840, 0.1470, 0.0229]) # sums to 1.0

Token 2 puts 69% of its attention on itself, 15% on "dessert", and spreads the rest thinly. These are the proportions of the final blend.

Why divide by $\sqrt{d_k}$? A dot product is a sum of $d_k$ terms, each with variance about 1, so the raw score's variance grows with $d_k$. Large scores push softmax into flat, saturated regions where gradients vanish. Dividing by $\sqrt{d_k}$ rescales the variance back to ~1, keeping training stable. It's a variance-control trick, nothing more mysterious.
06

The context vector — the payoff

Finally, the new representation of token 2 is the attention-weighted sum of all value vectors. This is the "weighted cocktail": each value poured in proportion to its attention weight.

$$ z^{(2)} = \sum_{j} \alpha_{2,j}\,v^{(j)} $$
context_vector_2 = attention_weights_2 @ values   # shape [4]
tensor([0.5313, 1.3607, 0.7891, 1.3110])

That's it — token "is" has been rewritten as a 4-D vector that folds in context from the whole sentence (mostly itself and "dessert"). Do this for all six tokens and you've run self-attention. The output is longer ($d_v=4$) than the input ($d=3$) here, but that size is your choice.

08

The whole thing as one class

All six steps collapse into a compact, reusable PyTorch module. The forward does it for every token at once with matrix multiplication — no loops.

import torch.nn as nn

class SelfAttention(nn.Module):
    def __init__(self, d_in, d_out_kq, d_out_v):
        super().__init__()
        self.d_out_kq = d_out_kq
        self.W_query = nn.Parameter(torch.rand(d_in, d_out_kq))
        self.W_key   = nn.Parameter(torch.rand(d_in, d_out_kq))
        self.W_value = nn.Parameter(torch.rand(d_in, d_out_v))

    def forward(self, x):
        queries = x @ self.W_query
        keys    = x @ self.W_key
        values  = x @ self.W_value
        attn_scores  = queries @ keys.T                       # [T, T] raw ω
        attn_weights = torch.softmax(
            attn_scores / self.d_out_kq**0.5, dim=-1)      # scaled softmax → α
        context_vec  = attn_weights @ values                  # [T, d_v]
        return context_vec

torch.manual_seed(123)
sa = SelfAttention(d_in=3, d_out_kq=2, d_out_v=4)
print(sa(embedded_sentence))
tensor([[-0.1564, 0.1028, -0.0763, -0.0764], [ 0.5313, 1.3607, 0.7891, 1.3110], ← matches context_vector_2 [-0.3542, -0.1234, -0.2627, -0.3706], [ 0.0071, 0.3345, 0.0969, 0.1998], [ 0.1008, 0.4780, 0.2021, 0.3674], [-0.5296, -0.2799, -0.4107, -0.6006]])

Row 2 is exactly the context_vector_2 we computed by hand — the class just does all six rows together.

09

Multi-head attention

One attention head learns one way of relating tokens. Multi-head attention runs several heads in parallel — each with its own $W_q,W_k,W_v$ — and concatenates their outputs. Like multiple kernels in a CNN, each head can specialize: one tracks grammar, another tracks subject–object links, another long-range topic.

class MultiHeadAttentionWrapper(nn.Module):
    def __init__(self, d_in, d_out_kq, d_out_v, num_heads):
        super().__init__()
        self.heads = nn.ModuleList(
            [SelfAttention(d_in, d_out_kq, d_out_v) for _ in range(num_heads)])

    def forward(self, x):
        return torch.cat([head(x) for head in self.heads], dim=-1)

torch.manual_seed(123)
mha = MultiHeadAttentionWrapper(d_in=3, d_out_kq=2, d_out_v=1, num_heads=4)
print(mha(embedded_sentence).shape)
torch.Size([6, 4]) # 6 tokens × (4 heads · 1 dim each)
Why not just one bigger head? Widening a single head gives more capacity, but every dimension still shares one attention pattern. Multiple heads give multiple independent attention patterns, so the model can attend to different things simultaneously. The 7B Llama 2 model uses 32 heads.

A friendlier example — 2 heads, by intuition

Imagine the sentence "the cat that chased the mouse was fast." Reading the word "was":

HeadWhat it learns to focus on"was" attends most to…
Head 1 · grammarsubject–verb agreement"cat" (the subject)
Head 2 · recencynearby words"mouse", "chased"

Head 1 keeps the grammar straight ("cat … was", not "mice … were"); head 2 keeps local meaning. Concatenating them gives "was" a representation that knows both its subject and its neighbourhood — something a single attention pattern couldn't capture at once.

10

Causal (masked) self-attention

GPT-style models generate text left-to-right, so when predicting the next word a token must not peek at words that come after it. Causal self-attention enforces this by masking out the upper triangle of the attention matrix — every token may attend only to itself and earlier tokens.

The clean way: set the future scores to $-\infty$ before softmax. Since $e^{-\infty}=0$, those positions get exactly zero weight and the rows still sum to 1 automatically — no renormalization needed.

block_size = attn_scores.shape[0]                       # 6
mask = torch.triu(torch.ones(block_size, block_size), diagonal=1)
masked = attn_scores.masked_fill(mask.bool(), -torch.inf)   # future → -inf
attn_weights = torch.softmax(masked / d_out_kq**0.5, dim=1)
tensor([[1.0000, 0.0000, 0.0000, 0.0000, 0.0000, 0.0000], [0.0532, 0.9468, 0.0000, 0.0000, 0.0000, 0.0000], [0.3862, 0.1214, 0.4924, 0.0000, 0.0000, 0.0000], [0.2232, 0.3242, 0.2078, 0.2449, 0.0000, 0.0000], [0.1536, 0.3145, 0.1325, 0.1849, 0.2145, 0.0000], [0.1973, 0.0247, 0.3102, 0.1132, 0.0751, 0.2794]])

Each row is a clean probability distribution over the current and previous tokens only. Row 1 ("Life") can attend only to itself; row 6 ("first") sees everything. That triangular shape is what makes autoregressive generation possible.

Intuition: picture reading a sentence with a sheet of paper sliding left to right, covering the words you haven't reached yet. The model predicts the next word using only what's uncovered — exactly how it will be used at generation time.
11

Cross-attention — two sequences talking

Everything so far was self-attention: queries, keys and values all came from one sequence. In cross-attention, the query comes from one sequence and the keys/values from another. This is how a translation decoder looks back at the encoded source sentence, or how an image caption attends to image patches.

$$ q^{(i)} = x_{1}^{(i)}\,W_q, \qquad k^{(j)} = x_{2}^{(j)}\,W_k, \qquad v^{(j)} = x_{2}^{(j)}\,W_v $$

Only one line of the class changes — keys and values read a second input:

class CrossAttention(nn.Module):
    def __init__(self, d_in, d_out_kq, d_out_v):
        super().__init__()
        self.d_out_kq = d_out_kq
        self.W_query = nn.Parameter(torch.rand(d_in, d_out_kq))
        self.W_key   = nn.Parameter(torch.rand(d_in, d_out_kq))
        self.W_value = nn.Parameter(torch.rand(d_in, d_out_v))

    def forward(self, x_1, x_2):            # x_1 = queries' source, x_2 = the "memory"
        queries = x_1 @ self.W_query
        keys    = x_2 @ self.W_key             # keys/values from the OTHER sequence
        values  = x_2 @ self.W_value
        attn_scores  = queries @ keys.T
        attn_weights = torch.softmax(attn_scores / self.d_out_kq**0.5, dim=-1)
        return attn_weights @ values

The query and key/value sequences may even have different lengths — only $d_q=d_k$ must hold for the dot product; $d_v$ stays free. That's the entire trick behind encoder–decoder transformers.

One picture for all four: self-attention is a sentence talking to itself; causal attention is the same but only looking left; cross-attention is one sentence questioning another; multi-head is any of these run several times in parallel and stitched together.
context = Σ (attention · value)
Every token, rewritten by everything it pays attention to.
