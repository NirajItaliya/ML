01 / THE FOUNDATION

The Single Layer Perceptron

Before networks, there was the perceptron — one artificial neuron. Everything else is just this idea, repeated and stacked.

Intuition

A perceptron is a tiny decision-maker. It takes a few numbers, decides how much each one matters, adds them up, and produces an answer. Think of approving a loan: income matters a lot (big weight), favourite colour matters not at all (zero weight). The neuron weighs the evidence, sums it, and fires a verdict.

Weight — a number that says how strongly one input pushes the result. Big positive = strong yes-vote. Negative = a vote against.
Bias — a baseline nudge added to the total, like a built-in lean toward "yes" or "no" before any input arrives.

The Mathematics

$$ y \;=\; f\!\left(\mathbf{w}\cdot\mathbf{x} + b\right) \;=\; f\!\left(\textstyle\sum_i w_i x_i + b\right) $$

$\mathbf{x}$ — the input vector, e.g. [1.2, 0.5]

$\mathbf{w}$ — the weight vector, one weight per input (learned)

$\mathbf{w}\cdot\mathbf{x}$ — the dot product: multiply matching pairs and sum, $w_1x_1 + w_2x_2 + \dots$

$b$ — the bias, one number shifting the total

$f$ — the activation function: turns the raw sum into the output

The Code

import numpy as np

def step(z):
    return 1 if z >= 0 else 0      # fire or don't

def slp_forward(x, w, b):
    z = np.dot(w, x) + b            # weighted sum + bias
    return step(z)                  # activation

x = np.array([1.2, 0.5])
w = np.array([0.8, -0.4])
b = 0.1
print(slp_forward(x, w, b))      # -> 1
02 / THE EVOLUTION

The Multi-Layer Perceptron

Intuition

One perceptron can only split data with a single straight line. Plenty of real problems can't be cut that way. The textbook example is XOR: output 1 when the inputs differ, 0 when they match.

x₁x₂XOR
000
011
101
110

No single straight line separates the 1s from the 0s. The fix is two ideas working together:

Hidden layer — a layer of neurons between input and output whose values you don't read directly; they feed the next layer. Stacking them lets simple boundaries combine into complex ones.
Non-linear activation — a curvy function (sigmoid, tanh, ReLU) applied after each sum. Without it, depth is useless: a chain of linear steps collapses back into one straight line.

We actually solve XOR by hand in Example D below — watch two simple neurons combine into a boundary no single line could draw.

✎ END-TO-END BY HAND

The full math, no code

Six networks, each computed start to finish — every multiply, every sum, every activation. Unless noted we use the sigmoid $\sigma(z)=\dfrac{1}{1+e^{-z}}$. Handy values: $\sigma(0)=0.500,\ \sigma(0.5)\approx0.622,\ \sigma(1)\approx0.731,\ \sigma(-0.5)\approx0.378$.

A · Two inputs → one hidden layer of 3 → one output

This is the "2 inputs, 3 hidden → weights are 3×2" case. The weight matrix $W^{1}$ has 3 rows (one per hidden neuron) and 2 columns (one per input). Read row $i$ as "the weights neuron $i$ uses on each input."

GIVENS x = [1, 0]

W¹ (3×2) = [ [ 0.5, -0.6],
            [ 0.3,  0.8],
            [-0.4,  0.2] ]
b¹ = [0.1, -0.2, 0.0]

W² (1×3) = [0.7, -0.9, 0.5]   b² = [0.05]
STEP 1 — HIDDEN PRE-ACTIVATIONS  z¹ = W¹x + b¹
z¹₁ = (0.5)(1) + (-0.6)(0) + 0.1 = 0.600
z¹₂ = (0.3)(1) + ( 0.8)(0) - 0.2 = 0.100
z¹₃ = (-0.4)(1)+ ( 0.2)(0) + 0.0 = -0.400
STEP 2 — HIDDEN ACTIVATIONS  a¹ = σ(z¹)
a¹₁ = σ(0.600) ≈ 0.6457
a¹₂ = σ(0.100) ≈ 0.5250
a¹₃ = σ(-0.400) ≈ 0.4013
STEP 3 — OUTPUT PRE-ACTIVATION  z² = W²·a¹ + b²
z² = (0.7)(0.6457) + (-0.9)(0.5250) + (0.5)(0.4013) + 0.05
   = 0.4520 - 0.4725 + 0.2007 + 0.05 ≈ 0.2302
STEP 4 — FINAL OUTPUT  ŷ = σ(z²)
ŷ = σ(0.2302) ≈ 0.5573

Two inputs entered, three neurons each computed a weighted sum and squashed it, the output neuron combined those three signals into one number. That is a complete forward pass.

B · Two inputs → hidden(3) → hidden(3) → one output

Now there are two hidden layers. The output of layer 1 becomes the input to layer 2 — that hand-off is the whole idea of "feed-forward." Shapes: $W^{1}$ is 3×2, $W^{2}$ is 3×3, $W^{3}$ is 1×3.

GIVENS x = [1, 0]

W¹(3×2)=[[0.5,-0.6],[0.3,0.8],[-0.4,0.2]]  b¹=[0.1,-0.2,0.0]
W²(3×3)=[[0.2,-0.3,0.6],[0.7,0.1,-0.5],[-0.2,0.4,0.3]]  b²=[0.0,0.1,-0.1]
W³(1×3)=[0.6,-0.4,0.9]  b³=[0.05]
STEP 1 — LAYER 1 PRE-ACTIVATIONS  z¹ = W¹x + b¹
z¹₁ = 0.5(1) - 0.6(0) + 0.1 = 0.600
z¹₂ = 0.3(1) + 0.8(0) - 0.2 = 0.100
z¹₃ = -0.4(1)+ 0.2(0) + 0.0 = -0.400
STEP 2 — LAYER 1 ACTIVATIONS  a¹ = σ(z¹)
a¹ ≈ [ σ(0.600), σ(0.100), σ(-0.400) ] ≈ [ 0.6457, 0.5250, 0.4013 ]
STEP 3 — LAYER 2 PRE-ACTIVATIONS  z² = W²a¹ + b²
z²₁ = 0.2(0.6457) - 0.3(0.5250) + 0.6(0.4013) + 0.0 = 0.2124
z²₂ = 0.7(0.6457) + 0.1(0.5250) - 0.5(0.4013) + 0.1 = 0.4038
z²₃ = -0.2(0.6457)+ 0.4(0.5250) + 0.3(0.4013) - 0.1 = 0.1013
STEP 4 — LAYER 2 ACTIVATIONS  a² = σ(z²)
a² ≈ [ σ(0.2124), σ(0.4038), σ(0.1013) ] ≈ [ 0.5529, 0.5996, 0.5253 ]
STEP 5 — OUTPUT  z³ = W³·a² + b³,  ŷ = σ(z³)
z³ = 0.6(0.5529) - 0.4(0.5996) + 0.9(0.5253) + 0.05 ≈ 0.6147
ŷ = σ(0.6147) ≈ 0.6490

Same recipe, run three times: each layer turns its incoming vector into an outgoing vector, then passes it forward. Add a hundred layers and nothing about the procedure changes.

C · Two inputs → hidden(3) → two outputs

Multiple outputs are just multiple output neurons sharing the same hidden layer — useful when you predict several things at once. The output weight matrix $W^{2}$ is now 2×3: 2 output neurons, each reading all 3 hidden signals.

GIVENS x = [1, 0]

W¹(3×2)=[[0.5,-0.6],[0.3,0.8],[-0.4,0.2]]  b¹=[0.1,-0.2,0.0]
W²(2×3)=[[0.7,-0.9,0.5],[-0.3,0.6,0.8]]  b²=[0.05,-0.1]
STEP 1 & 2 — HIDDEN LAYER (identical to Example A)
z¹ = [0.600, 0.100, -0.400]
a¹ = σ(z¹) ≈ [ 0.6457, 0.5250, 0.4013 ]
STEP 3 — OUTPUT PRE-ACTIVATIONS  z² = W²a¹ + b²
z²₁ = 0.7(0.6457) - 0.9(0.5250) + 0.5(0.4013) + 0.05 ≈ 0.2302
z²₂ = -0.3(0.6457)+ 0.6(0.5250) + 0.8(0.4013) - 0.1 ≈ 0.3423
STEP 4 — FINAL OUTPUTS  ŷ = σ(z²)
ŷ₁ = σ(0.2302) ≈ 0.5573
ŷ₂ = σ(0.3423) ≈ 0.5848

Two answers from one network. The hidden layer is computed once and shared; only the output layer widens. (For probabilities that sum to 1 you'd swap the output sigmoid for softmax, but the weighted-sum step is the same.)

D · Solving XOR by hand (2 → 2 → 1)

Here we finally beat XOR. We use the step activation (fires 1 when $z\ge 0$, else 0) so the arithmetic stays whole-number and the logic is crystal clear. The trick: one hidden neuron learns OR, the other learns AND, and the output computes "OR but not AND" — which is exactly XOR.

GIVENS (step activation) W¹(2×2)=[[1, 1],   # h₁: OR detector
          [1, 1]]   # h₂: AND detector
b¹ = [-0.5, -1.5]
W²(1×2)=[ 1, -1]   b² = [-0.5]  # h₁ AND (NOT h₂)
CHECK ALL FOUR INPUTS  h = step(W¹x + b¹),  y = step(W²h + b²)
x = [0,0] → h₁=step(-0.5)=0, h₂=step(-1.5)=0 → y=step(0-0-0.5)=0 ✓
x = [0,1] → h₁=step( 0.5)=1, h₂=step(-0.5)=0 → y=step(1-0-0.5)=1 ✓
x = [1,0] → h₁=step( 0.5)=1, h₂=step(-0.5)=0 → y=step(1-0-0.5)=1 ✓
x = [1,1] → h₁=step( 1.5)=1, h₂=step( 0.5)=1 → y=step(1-1-0.5)=0 ✓

All four rows of the XOR table reproduced exactly. $h_1$ fires when at least one input is on (OR); $h_2$ fires only when both are on (AND); the output keeps the cases that are OR-true but AND-false — the "exactly one" cases. One hidden layer was all it took.

Why this matters: a single perceptron cannot produce this table no matter how you set its weights. Adding one hidden layer with a non-linear activation unlocked a boundary that bends. That is the entire reason deep networks exist.

E · A ReLU network (2 → 3 → 1)

Modern networks rarely use sigmoid in hidden layers — they use ReLU: $\text{ReLU}(z)=\max(0,z)$. It is cheap, and it lets large signals pass undimmed. Here the hidden layer uses ReLU and the output is linear (identity), a common setup for regression.

GIVENS (ReLU hidden, linear output) x = [1, 2]
W¹(3×2)=[[0.5,-0.3],[-0.2,0.4],[0.1,0.1]]  b¹=[0.0, 0.5, -0.3]
W²(1×3)=[0.6,-0.5,0.9]  b²=[0.2]
STEP 1 — HIDDEN PRE-ACTIVATIONS  z¹ = W¹x + b¹
z¹₁ = 0.5(1) - 0.3(2) + 0.0 = -0.100
z¹₂ = -0.2(1)+ 0.4(2) + 0.5 = 1.100
z¹₃ = 0.1(1) + 0.1(2) - 0.3 = 0.000
STEP 2 — ReLU  a¹ = max(0, z¹)
a¹₁ = max(0, -0.100) = 0.000  ← neuron "off"
a¹₂ = max(0,  1.100) = 1.100
a¹₃ = max(0,  0.000) = 0.000
STEP 3 — LINEAR OUTPUT  ŷ = W²·a¹ + b²
ŷ = 0.6(0.000) - 0.5(1.100) + 0.9(0.000) + 0.2
  = 0 - 0.550 + 0 + 0.2 = -0.350

Two of the three neurons output exactly 0 — ReLU switches neurons off whenever their sum is negative. This "sparsity" is a feature: only the relevant neurons contribute, and gradients flow cleanly through the ones that are on.

Why ReLU over sigmoid? Sigmoid squashes everything into (0,1) and its slope nearly vanishes for large inputs, which stalls learning in deep nets ("vanishing gradients"). ReLU keeps a slope of 1 for positive inputs, so signals and gradients survive through many layers.

F · Scaling up — counting the parameters

You don't always work every number by hand — but you should always be able to say how big a network is. The rule for one layer:

$$ \text{params}(\text{layer}) = \underbrace{(\text{neurons}\times\text{inputs})}_{\text{weights}} + \underbrace{\text{neurons}}_{\text{biases}} $$

Take a network that maps 4 inputs → 6 hidden → 3 outputs (think: 4 sensor readings into 3 class scores). Walk it layer by layer:

SHAPES & PARAMETER COUNT Layer 1 (hidden): W¹ is 6×4 → 24 weights + 6 biases = 30
Layer 2 (output): W² is 3×6 → 18 weights + 3 biases = 21
 
TOTAL trainable parameters = 30 + 21 = 51

The forward pass is still just $\mathbf{z}=W\mathbf{a}+b$ then $\mathbf{a}=f(\mathbf{z})$, twice. The only thing that grew is the number of multiply-adds — from a handful to fifty-one. Real networks push this into the millions or billions, but the bookkeeping never changes.

Sanity check you can always run: a weight matrix for a layer is always (neurons in this layer) × (signals coming in), and there is exactly one bias per neuron. If your shapes don't line up for the multiplication $W\mathbf{a}$, the network can't run — the column count of $W$ must equal the length of $\mathbf{a}$.
The pattern, for any shape: for each layer compute $\mathbf{z} = W\mathbf{a} + b$ ($\mathbf{a}$ is the previous layer's output, or $\mathbf{x}$ for the first layer), then $\mathbf{a} = f(\mathbf{z})$, and pass $\mathbf{a}$ forward. A weight matrix is always (neurons in this layer) × (signals coming in).

03 / THE COMPLETE PICTURE

The Feed-Forward Neural Network

Intuition

An FFNN is the MLP generalized: an input layer, any number of hidden layers of any width, and an output layer. "Feed-forward" means data moves in one direction — input toward output. No loops, no backward edges. Each layer's output becomes the next layer's input. That pass is forward propagation.

Heads up: training uses backpropagation — a separate backward pass that adjusts weights to cut error. Prediction-time flow is always strictly forward. Backprop is how it learns; forward-prop is how it answers.

Core mechanics — the recap

x

Inputs

Raw feature values fed into the first layer, as a vector.

w

Weights

One per connection. Matrix shape = (neurons) × (incoming signals). Learned in training.

b

Biases

One per neuron. Shift the sum before activation, so neurons can fire even at zero input.

Σ

Weighted Sum

Every neuron computes $z = W\mathbf{a} + b$ before anything else.

f

Activation

A non-linear function on each sum. The source of the network's power to model curves.

→

Forward Prop

Repeat "sum → activate" layer by layer until the prediction appears.

The full thing in code

import numpy as np
def sigmoid(z): return 1/(1+np.exp(-z))

def ffnn_forward(x, layers):
    """layers = list of (W, b). Data flows strictly forward."""
    a = x
    for W, b in layers:
        a = sigmoid(W @ a + b)   # sum -> activate -> feed forward
    return a

# 2 inputs -> 3 hidden -> 3 hidden -> 1 output  (Example B)
net = [
    (np.random.randn(3, 2), np.zeros(3)),
    (np.random.randn(3, 3), np.zeros(3)),
    (np.random.randn(1, 3), np.zeros(1)),
]
print(ffnn_forward(np.array([1.0, 0.0]), net))

Same loop, any depth. That single for loop is a feed-forward neural network.
